# Mi Proyecto

Este directorio está preparado para publicar la app en GitHub Pages.

## Pasos para publicar

1. Compila el proyecto con:
   ```bash
   npm run build
   ```
2. Sube el contenido de la carpeta `dist` a la rama `gh-pages` o usa GitHub Actions.
3. En GitHub Pages, selecciona la rama correspondiente y la carpeta `root` o `docs`.
